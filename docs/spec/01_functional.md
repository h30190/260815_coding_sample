# 第一章：功能規格書 (01_functional.md)

本文件說明 ArchClock 本地單機網頁版的功能規格與業務邏輯。

---

## 1. 個人檔案設定 (User Profile Setup)
- **觸開條件**：首次進入系統且瀏覽器中無儲存的 `archclock_user` 時，會呈現「設定個人檔案」畫面。
- **輸入欄位**：
  - **員工姓名**：必填，純文字。
  - **職級**：必選下拉選單，包括 `Architect (建築師)`、`Staff (員工)`、`Admin (管理員)`。
  - **辦公室**：必填，預設為 `Taipei Headquarters`。
- **流程**：點擊「進入系統」後，資料將儲存至 `localStorage`。系統狀態切換至已登入，直接跳轉至儀表板，並在頂部導覽列顯示使用者姓名與職級。

---

## 2. 打卡功能 (Clock In / Out)
- **入口**：位於「打卡與記錄」分頁。
- **操作**：
  - **上班打卡 (Clock In)**：記錄打卡當前時間、打卡類型為 `clock_in`。
  - **下班打卡 (Clock Out)**：記錄打卡當前時間、打卡類型為 `clock_out`。
- **定位資訊**：
  - 打卡時系統會透過瀏覽器 GPS API 取得目前的經度、緯度及精確度。
  - **外點打卡 (Field Site)**：勾選後，使用者可以手動輸入工地或建案名稱。外點打卡**必須具備定位權限**；若是辦公室打卡（未勾選外點），若定位失敗，則系統會預設為定位名稱為 `Office`。
- **備註**：使用者可以在打卡時輸入選填的備註內容。

---

## 3. 近期打卡歷史紀錄 (Recent Activity)
- **展示**：列出該使用者最近 20 筆打卡紀錄。
- **細節**：
  - 上班打卡在左側顯示綠色垂直線條。
  - 下班打卡在左側顯示灰色垂直線條。
  - 顯示詳細的打卡年月日、星期、以及時分秒。
  - 若是外點打卡，會額外顯示工地或建案名稱。

---

## 4. 工時統計功能 (Work Hours Calculator)
- **入口**：位於「工時統計」分頁。
- **統計卡片**：
  - **今日工時**：統計當天已完成的工時（下班時間 - 上班時間）。若使用者目前已上班打卡但尚未下班，會自動將當前時間與上班時間相減納入動態累計，並閃爍顯示 `計算中 (已登入)`。
  - **本週總工時**：累計週一至週日的所有已完成工時，以小時為單位展示。
- **每日明細清單**：
  - 依日期（倒序，最新在前）列出每一天。
  - 顯示當天的第一個上班打卡時間與最後一個下班打卡時間，並呈現當天計算出的總工時。

---

## 5. 看板專案管理 (Kanban Project Management)
- **入口**：位於「專案管理」分頁（在此分頁中，版面寬度會自動從 `max-w-4xl` 動態擴展為 `max-w-7xl`）。
- **看板狀態**：
  - **待處理 (Backlog)**：新建立的任務。
  - **進行中 (In Progress)**：開始執行的任務。
  - **審核中 (Review)**：執行完畢待確認。
  - **已完成 (Done)**：結案任務。
- **卡片屬性**：任務 ID、標題、詳細描述、指派人、優先級（高/中/低）、到期日。
- **卡片操作**：
  - **拖曳移動**：支援滑鼠直接拖曳卡片至目標看板欄位。
  - **快速按鈕**：卡片悬浮時提供「推進」與「退回」按鈕，方便觸控設備操作。
  - **刪除**：卡片右上角提供刪除按鈕。
